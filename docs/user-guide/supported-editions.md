## Detailed Edition Specifications

### 1. Community Edition
- Completely free and open source under Apache 2.0.
- Runs without user accounts, license files, telemetry, or network connectivity.
- Provides standard linting, AST syntax repair, test discovery, and local audit logging.

### 2. Pro Local
- Priced at £19.00/month or £190.00/year (includes UK VAT where applicable; 2 months free with annual billing).
- Designed for autonomous AI agents and individual senior developers.
- Features isolated git sandboxes, advanced AST repairs, database migration safety guards, and token usage metrics.
- Uses cryptographic Ed25519 offline capability tickets with a 30-day renewal cycle and 7-day grace period.

### 3. Team Edition
- Priced at £15.00/seat/month or £150.00/seat/year, subject to a minimum of 5 seats (£75/month or £750/year).
- Named developer seat allocation with support for floating developer pools.
- Centralized team policy synchronization and aggregated audit metrics.

### 4. Enterprise Edition
- Designed for defense, finance, and secure infrastructure.
- Zero network connectivity requirement; supports permanent offline perpetual cryptographic certificates.
- Custom invariant rules, monorepo transaction locking, and priority SLA support.

### 5. OEM Edition
- Designed for developer tooling platforms, CI/CD vendors, and autonomous AI coding systems.
- Headless, zero-overhead programmatic JSON contracts (`invocation-contract.v1.json` and `diagnostic-contract.v1.json`).
- Built-in token metrics and ROI accounting.
